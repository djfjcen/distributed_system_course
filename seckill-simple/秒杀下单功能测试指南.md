## 3. 秒杀下单（核心接口）
**说明**：POST /api/orders/seckill 支持两种方式：
- **方式A**：使用会话（用户登录后）  
- **方式B**：用查询参数 `userId` 快速测试

### 方式B 示例：
```bash
curl -X POST 'http://localhost/api/orders/seckill?userId=1' \
  -H "Content-Type: application/json" \
  -d '{"productId":1,"quantity":5}'
```

**响应示例**
```json
{
  "success": true,
  "message": "seckill order created",
  "data": {
    "id": 724517141545086976,
    "userId": 1,
    "productId": 1,
    "quantity": 5,
    "price": 399.00,
    "status": 0,
    "createdAt": "2026-03-21T10:15:30",
    "updatedAt": "2026-03-21T10:15:30"
  }
}
```

### PowerShell 示例（避免中文乱码）：
```powershell
Invoke-RestMethod -Uri 'http://localhost/api/orders/seckill?userId=1' `
  -Method Post -ContentType 'application/json' `
  -Body '{"productId":1,"quantity":5}' | ConvertTo-Json -Depth 8
```

## 工作流演示

### 完整秒杀场景测试

**1. 注册两个用户**
```powershell
# 用户 A
$userA = Invoke-RestMethod -Uri 'http://localhost/api/auth/register' `
  -Method Post -ContentType 'application/json' `
  -Body '{"username":"userA","password":"pass123","email":"a@test.com"}'

# 用户 B
$userB = Invoke-RestMethod -Uri 'http://localhost/api/auth/register' `
  -Method Post -ContentType 'application/json' `
  -Body '{"username":"userB","password":"pass123","email":"b@test.com"}'

echo "User A ID: $($userA.userId), User B ID: $($userB.userId)"
```

**2. 查看商品库存**
```powershell
$products = Invoke-RestMethod -Uri 'http://localhost/api/products'
$products.value | Format-Table id, name, stock
```

**3. 两个用户同时秒杀（消息队列削峰）**
```powershell
# 用户 A 秒杀商品 1，数量 10
$order1 = Invoke-RestMethod -Uri 'http://localhost/api/orders/seckill?userId=1' `
  -Method Post -ContentType 'application/json' `
  -Body '{"productId":1,"quantity":10}'

# 用户 B 秒杀商品 1，数量 15  
$order2 = Invoke-RestMethod -Uri 'http://localhost/api/orders/seckill?userId=2' `
  -Method Post -ContentType 'application/json' `
  -Body '{"productId":1,"quantity":15}'

echo "Order 1 ID: $($order1.data.id)"
echo "Order 2 ID: $($order2.data.id)"
```

**4. 用户 A 再次尝试秒杀商品 1（幂等性测试）**
```powershell
$order1_retry = Invoke-RestMethod -Uri 'http://localhost/api/orders/seckill?userId=1' `
  -Method Post -ContentType 'application/json' `
  -Body '{"productId":1,"quantity":5}'

# 应该返回同一个订单 ID（不会创建新订单）
echo "Same order? $(($order1_retry.data.id) -eq ($order1.data.id))"
```

**5. 查询用户 A 的所有订单**
```powershell
$myOrders = Invoke-RestMethod -Uri 'http://localhost/api/orders/user/1'
$myOrders.data | Format-Table id, productId, quantity, status
```

## 架构亮点说明

### 1. **削峰填谷**
- 秒杀请求立即返回（快速响应用户）
- 消息写入 Kafka 队列
- 后端异步消费处理（控制处理速度）

### 2. **幂等性保证**
- Redis 中使用唯一键 `order:idempotent:{userId}:{productId}`
- 同一用户同一商品只能秒杀一次
- 重复请求返回已存在订单，不创建新记录

### 3. **库存一致性**
- Redis 缓存库存（快速扣减）
- 检查缓存库存 → 扣减缓存 → 保存到数据库
- 防止超卖

### 4. **分布式ID**
- 雪花算法生成全局唯一订单 ID
- 不依赖数据库自增，支持分布式扩展
- ID 包含时间戳、机器ID、序列号

### 5. **异步处理**
- Kafka 消费者异步创建订单记录
- 数据库最终一致性
- 即使消费失败，订单记录已在本地存储
